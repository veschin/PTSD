PTSD

Structured AI Development Pipeline

CLI tool enforcing PRD -> Tests -> Implementation for AI-driven projects. No skipping. No orphans. No vibes.

go install github.com/veschin/ptsd/cmd/ptsd@latest
Zero deps Single binary 22 commands

How It Works

1
Context
Session starts -- pipeline state injected. AI sees what to do next.
2
Gate
Every file write is checked. Wrong stage? Blocked.
3
Track
Artifacts created -- stage advances automatically.
4
Validate
Commit hook runs full check. Nothing slips through.

Pipeline Profiles

Not every feature needs five stages. Choose what fits.

full
PRD → Seed → BDD → Tests → Impl
Data-heavy features. Golden seed data grounds BDD scenarios.
standard
PRD → Seed → BDD → Tests → Impl
Default. Most features. BDD from PRD, skip seed ceremony.
lite
PRD → Seed → BDD → Tests → Impl
Simple utilities. Tests directly from PRD. Ship fast.

What's New in v2

Pipeline Profiles

Three profiles per feature. Full, standard, lite. Skip what you don't need.

Polyglot

Go, TypeScript, Python, Rust, Ruby, Java, C#. Auto-detected.

Tool Adapters

Claude Code, OpenCode, Cursor. One pipeline, any tool.

Smart Adopt

Bootstrap existing projects. Features auto-discovered from tests.

Quick Start

# install
go install github.com/veschin/ptsd/cmd/ptsd@latest

# initialize in your project
cd my-project && git init
ptsd init --tool claude

# add your first feature
ptsd feature add auth "Auth" --pipeline standard
